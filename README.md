# 沖縄 旅のしおり（11/28〜12/1）

## 友達に送るURL

https://bee-dot-gum.github.io/okinawa-trip/

ログインなしで開けます。スマホのSafari（AndroidはChrome）で開いて「ホーム画面に追加」すると、アプリのように使えます。

## ホーム画面への追加

- iPhone：LINEで開いたら、メニューから「Safariで開く」→ 共有ボタン（□に↑）→「ホーム画面に追加」
- Android：Chromeで開く → 右上の「⋮」→「ホーム画面に追加」

## 中身

- ホーム：搭乗券風の表紙、出発までの日数、沖縄の4日間のルート地図、予算の目安
- 予定：日ごとの予定。旅行の当日は「いま・つぎ」が出る。雨モードあり
- ルート：地図とルート図、移動時間
- チェック：予約・やること・持ち物（各スマホに保存）
- メモ：乗り遅れ注意の時刻、予約番号や電話番号（各スマホに保存）

## 更新のしかた

1. 新しい index.html を「Add file」→「Upload files」で上書きアップロード
2. 「Commit changes」を押す
3. 1〜2分で上のURLに反映

## 注意

- このリポジトリとURLは公開です。予約番号・電話番号はアプリのメモ欄（各スマホの中だけに保存）に入れて、ファイル本体には書かないこと
- 料金・時間は11/25時点の目安です
- 便名と時刻は公開情報なので載せています。予約番号・名前・会員番号・座席番号・宿の住所は載せないこと
